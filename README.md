🩺 Healthcare Diagnosis App
📊 Machine Learning Project for Predicting Multiple Diseases

Developed by: Gouri Sunil Kumar
Accuracy: ~92% using Random Forest Classifier
Tech Stack: Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Streamlit

📘 Overview

The Healthcare Diagnosis App is a machine learning–based system that predicts the likelihood of multiple diseases using patient health data.
It demonstrates how data analysis and classification techniques can help in early disease detection and diagnosis.

🧠 Diseases Predicted:

Diabetes

Heart Disease

Hypertension

Kidney Disease

Healthy (No major condition)

⚙️ Features

Performs Exploratory Data Analysis (EDA) on healthcare data

Uses Random Forest Classifier for disease prediction

Achieved 92% model accuracy

Visualizes insights using Matplotlib and Seaborn

Includes optional Streamlit web app for real-time predictions

🧩 Dataset

The dataset (healthcare_data.csv) contains simulated patient records with the following attributes:

Feature	Description
Age	Patient age in years
BMI	Body Mass Index
Glucose	Glucose level (mg/dL)
BloodPressure	Blood pressure (mmHg)
Cholesterol	Cholesterol level (mg/dL)
HeartRate	Heart rate (bpm)
Diagnosis	Target disease label
🚀 How to Run the Project

Clone this repository:
git clone https://github.com/GOURI0630/Healthcare-Diagnosis-App.git

cd Healthcare-Diagnosis-App

Install dependencies:
pip install pandas numpy scikit-learn matplotlib seaborn streamlit

Run the Jupyter notebook:
jupyter notebook Healthcare_Diagnosis_App.ipynb

(Optional) Launch Streamlit web app:
streamlit run app.py
